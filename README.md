# Northline — Telegram-сценарий заявок

Клиентский бот digital-студии **Northline**: короткий опрос → карточка заявки в консоль.

Стек: Node 18+, Telegraf 4, long polling (удобно на Windows-ПК).

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather): `/newbot` → имя → username.
2. Скопируйте токен.
3. В этой папке:

```bash
copy .env.example .env
```

4. В `.env` укажите:

```env
BOT_TOKEN=123456:ABC...
BOT_USERNAME=YourBotUsername
MANAGER_CHAT_IDS=
```

5. Установка и запуск:

```bash
npm install
npm start
```

Для автоперезапуска при правках: `npm run dev`.

6. Напишите боту `/myid`, вставьте число в `MANAGER_CHAT_IDS`, перезапустите бота.  
   Менеджер должен хотя бы раз нажать `/start`.

7. Откройте бота в Telegram (`t.me/<BOT_USERNAME>`), пройдите сценарий.  
   Карточка придёт менеджеру в Telegram и в консоль.

## Сценарий

1. Старт → «Оставить заявку»
2. Услуга (кнопки)
3. Задача (текст)
4. Срок (кнопки или свой текст)
5. Бюджет (кнопки)
6. Контакт
7. Имя → подтверждение клиенту + лог в консоль

Команды: `/start`, `/cancel`, `/help`.

## Лендинг и портфолио

На лендинге (`U:\Лендинг`) ссылка на бота задаётся через:

```env
VITE_BOT_URL=https://t.me/YourBotUsername
```

Пока переменная пустая, кнопка «Открыть в Telegram» ведёт на `#` (заглушка).
